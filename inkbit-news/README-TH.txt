INKBIT NEWS - วิธีอัพขึ้น Vercel
================================
1) เปิดไฟล์ index.html ด้วย Notepad หาบรรทัด "EDIT HERE" (อยู่ท้ายไฟล์)
   - วางลิงก์ OpenSea ของแต่ละคอลใน world / pets / zombies (ในเครื่องหมาย " ")
   - ถ้ายังไม่มีลิงก์ ปล่อยว่างไว้ ปุ่มจะขึ้น "OpenSea link soon"
   - วันเปิดมิ้นท์ Inkbit World: ใส่ใน DROPS.world.start / end แบบ "2026-11-10T20:00:00+07:00"
   - เพิ่ม/แก้อีเวนต์ในปฏิทินได้ที่ EVENTS
2) ไป vercel.com > Add New > Project > ลากโฟลเดอร์ inkbit-news ทั้งโฟลเดอร์ (ที่มี index.html กับโฟลเดอร์ img) ลงไป > Deploy
3) อัพเดตข่าวครั้งต่อไป: แก้ไฟล์แล้วลากขึ้นโปรเจกต์เดิมอีกรอบ

สถานะ (Minting now / Mint ended / Coming soon) และตัวนับถอยหลังเปลี่ยนเองตามเวลา ไม่ต้องแก้มือ
ภาพตัวอย่างในเว็บเป็นตัวธรรมดาเท่านั้น ไม่มีตัวหายาก และไม่มีเลข token
